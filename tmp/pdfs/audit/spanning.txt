       Construction
  Core idea of the GHS construction
➢ Start with a forest of individual one-node components


➢ Repeatedly identify a minimum-weight outgoing edge (MWOE) for each
  component


➢ Merge components through the selected MWOE


➢ Repeat level by level until only one component remains


➢ Each component has a representative leader UID                  4
Level 0: the initial spanning forest

 With n nodes, level 0 contains n separate spanning trees


 Each component contains exactly one node and no selected
 edges


 Every node knows its own UID and acts as the leader of its
 component


 Nodes know their incident edges and their weights

 Why levels are essential

Components operate independently, so uncontrolled simultaneous merges could
create conflicts
Two level-0 components merge to form a level-1 component


A level-0 component and a level-1 component produce a level-1 component


Equal level merges advance to the next level


Leveling imposes order and prevents conflicting activity

                                                                          11
Termination: when is the MST complete?

Eventually the forest becomes one component


The leader starts another MWOE search


Every neighbor reports the same leader UID, so there is no edge to
another component


The leader knows that the entire network is covered by one spanning
tree and the construction can stop

Complexity analysis

At each level, O(n) time is required for message propagation and
processing


The number of levels is at most O(log n), because component sizes grow
geometrically


Time complexity - O(n log n)


Communication complexity: O((n + e) log n), where n is nodes and e is
edges
                                                                        14
 Why the MST is useful beyond construction

Once an MST exists, it provides a communication backbone for distributed
operations


Leaf nodes initiate a convergecast through the tree


Internal nodes combine information and forward it toward the remaining
neighbor


The tree structure makes global aggregation simpler than operating over the
original network

 Leader election over the constructed tree

➢ Each node has a unique, comparable UID
➢ Leaves initiate convergecast messages
➢ An internal node waits for messages from descendants, combines the
  information, and forwards it
➢ If two neighboring nodes remain as candidates, the node with the higher UID
  becomes leader
➢ MST construction therefore provides a reusable structure for later distributed
  algorithms
